# 🛠 实战案例

这里记录我**真正动手做过的事**。

和笔记不同，案例强调的是"过程"——包括卡住的地方和最终怎么解决的。

## 统一记录模板

建议每个案例都按这个结构写，方便日后检索复盘：

```md
## 目标
一句话说清楚要做什么。

## 环境与版本
记录关键版本号（避免以后复现不了）。

## 步骤
1. 第一步做了什么
2. 第二步做了什么

## 踩过的坑
- **现象**：XXXX 报错
- **原因**：XXXX
- **解法**：XXXX

## 最终成果
能用/能访问/截图。

## 复盘
学到了什么，下次可以怎么改进。
```

::: tip 为什么要记"踩过的坑"
案例真正的价值不在成功，而在**失败的部分**。三个月后遇到同样的报错，你会庆幸自己当时记下了解法。
:::

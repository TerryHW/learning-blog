## 一、提示框（最常用）

这是本站最实用的语法，用来高亮重点。

::: tip 提示
用于补充说明或推荐做法。
:::

::: info 信息
用于中性的背景说明。
:::

::: warning 注意
用于容易出错的地方。
:::

::: danger 危险
用于不可逆的高危操作。
:::

## 二、代码块

````md
```python
def hello(name):
    print(f"Hello, {name}!")
```
````

效果：

```python
def hello(name):
    print(f"Hello, {name}!")
```

### 高亮指定行

在语言后加 `{2,4-5}` 可以高亮第 2 行和第 4-5 行：

````md
```python {2}
def hello(name):
    print(f"Hello, {name}!")    # 这行会高亮
    return True
```
````

### 显示 diff

````md
```diff
-  const a = 1          // 删除的行
+  const a = 2          // 新增的行
   const b = 3
```
````

效果：

```diff
- const a = 1
+ const a = 2
  const b = 3
```

## 六、文章头（Frontmatter）

每个 `.md` 文件开头建议加上，利于 SEO 和标题显示：

```md
---
title: 文章标题
description: 一句话描述，会显示在搜索结果里
date: 2026-09-16
tags:
  - Git
  - 工具
---
```
